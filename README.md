## macOS — erste Installation (wichtig)

Die App ist noch nicht bei Apple notarisiert. Beim ersten Start:
1. DMG öffnen, **Alfred Wolf** in **Programme** ziehen.
2. **Rechtsklick auf die App → Öffnen** (einmalig).
3. Falls macOS blockiert, einmal im Terminal:
   `xattr -dr com.apple.quarantine "/Applications/Alfred Wolf.app"`

Voraussetzung: macOS 13+. Keine weiteren Installationen nötig — alles ist eingebaut.
